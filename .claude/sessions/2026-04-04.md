## Key Architectural Decisions Made

| Decision | Reason |
|---|---|
| `HttpClientFactory` + `ServerUrl` in `:shared/network` | Infrastructure belongs in shared, not in a feature module |
| `DefaultRequest` plugin for base URL + contentType | Eliminates duplication across all future API classes |
| `SERVER_BASE_URL` as expect/actual | Android emulator uses `10.0.2.2`, not `localhost` |
| `CustomerApi` separate from `CustomerRepositoryImpl` | API = network boundary; Repository = domain boundary |
| `HttpClient` as Koin `single` | One shared client instance across all API classes |
| `CustomerStorage` as in-memory `ConcurrentHashMap` | Placeholder — will be replaced by a real DB (e.g. Exposed + PostgreSQL) |

## Important Reminders
- After any `build-logic` / convention plugin change → **Gradle sync required**
- `implementation` in KMP is NOT transitive — if a module uses a type from a lib, it must declare that lib itself
- `DiModulePlugin` needed `ktor-client-core` explicitly because it references `HttpClient` as a type even though `:shared` already has it
